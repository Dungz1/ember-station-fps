Ember Station is a round-based 5v5 tactical shooter in three.js, set in a geothermal power station at dusk: buy your kit in freeze time, plant or defuse the reactor charge, and take rounds with hitscan gunplay, climbing recoil patterns, movement-tuned spread, and bots that patrol lanes, hear gunshots, and hold angles. Everything is original and self-contained — synthesized WebAudio sound, pooled effects, one 64 Hz simulation, and not a single network request or asset file.

## Run it

```
node serve.ts
```

Then open http://localhost:8080. No build step, no install: `game/` is plain ES modules with three.js vendored under `game/vendor/three/`.
